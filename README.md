# Week 9 Lab - 99 Bottles of Beer

This web page prints the lyrics of the traditional "99 Bottles of Beer" song using a JavaScript `for` loop.

## How to run

1. Download `index.html`.
2. Open it in a web browser.
3. Click **Show All Lyrics** to display all the verses.

## JavaScript features

- A `for` loop counts down from 99 to 1.
- `if` statements handle singular "bottle" and the final "no more bottles" line.
- `document.getElementById()` shows the generated lyrics on the page.

This is a Week 9 Loops lab for Web Design and Client Side Scripting.
